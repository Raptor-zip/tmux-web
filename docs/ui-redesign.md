# UI の作り直し（2026 年 11 月）：何がどこへ移ったか

画面に常に出す操作を、よく使うものと注意が必要な状態だけに絞った。
めったに使わない操作は、メニュー・パレット・「表示と接続」へ移した。**なくした機能はない。**
古い名前でパレット（`Alt+Shift+P`）を探しても、新しい操作が見つかる。

## 考え方

- すべての操作は `web/src/commands.ts` の登録表に 1 回だけ書く。メニュー・パレットの『操作』・
  ショートカット一覧（`Alt+/`）は、この表から作る。古いラベルは `aliases` に残し、検索で引けるようにしている。
- メニューの並びは `web/src/menus.ts` にまとめている。メニューは対象ごとに分けている：新規メニュー、タブメニュー、
  画面メニュー、ワークスペースのメニュー、一覧の ⋯・デバイス見出しの ⋯・行メニュー。
- 『閉じる』は表示から外すだけで、tmux は動いたまま。『終了…』はプロセスを止める（確認あり）。
  『削除…』は保存した設定を消す（確認あり）。取り消せない確認は、最初のフォーカスが『キャンセル』にある。
  まとめて閉じたときとパネルを閉じたときは、5 秒間『元に戻す』のトーストが出る。
- 仮想デスクトップは、画面では **ワークスペース** と呼ぶ。コードの名前（`desktops`、`tw.desktops`）と、
  保存済みの名前（「デスクトップ1」など）はそのまま。新しく作ると「ワークスペース N」になる。

## キーボード

一覧はアプリの中の「ショートカット一覧」（`Alt+/`）で見られる。この一覧は登録表のキー表記から作るので、
メニューの表記とずれない。新しく加えたキーは次のとおり。

| キー | 操作 |
| --- | --- |
| `Alt+Shift+T` | 新規メニュー（続けて T・C・X・R で選ぶ） |
| `Alt+Shift+C` / `Alt+Shift+X` | Claude / Codex を起動 |
| `Alt+Shift+P` | 探す・操作を『操作』で開く |
| `Alt+J` | 次の入力待ちの端末へ |
| `Alt+O` | 作業フォルダーを開く |
| `Alt+/` | ショートカット一覧 |

`Alt+1`〜`9`・`Alt+0`・`Alt+[` `Alt+]` は、見えているタブ列の順に数える（分割表示では入力先のパネルの中、
1 パネル表示ではワークスペース全体）。Alt のショートカットは「表示と接続」→「Alt ショートカット」で
まとめてオフにできる（設定 `tw.altKeys`、既定はオン）。オフのときは Alt キーがそのまま端末に届く。

## 新しい設定

| キー | 中身 | 既定 |
| --- | --- | --- |
| `tw.altKeys` | Alt ショートカットを使う | オン |
| `tw.inputBar` | 入力行：自動 / 常に表示 / 隠す。以前の `tw.keyBar.v2` がオンなら「常に表示」を引き継ぐ | 自動 |
| `tw.phoneTabs` | スマホでタブ列を表示 | オフ |
| `tw.landscapeHideHeader` | 横持ちで見出しを隠す | オフ |
| `tw.installHint` | 「アプリとして追加」の案内を出したかどうか | — |

文字サイズ・行間・接続方式・tmux のステータス行は、保存先のキーを変えずに、すべてのワークスペースで共通にした。

## 操作を足すとき

1. `web/src/commands.ts` に `define({ id, scope, group, label, … })` を足す。`label` は登録表の中で重複させない。
   キーがあるなら `hint` に書く（ショートカット一覧に自動で載る）。押せないときは `disabledReason` で理由を返す。
2. メニューに出すなら `web/src/menus.ts` の並びに id を足す。出さなくても、文脈があればパレットの『操作』に出る。
3. ラベルを変えるときは、前の名前を `aliases` に残す。ブラウザテスト（`web/test/*.cjs`）が名前で探しているので、同じ変更で直す。
