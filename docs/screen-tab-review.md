# リモートデスクトップのタブ

リモートデスクトップ（VNC）と端末を同時に見られるよう、画面をタイルのタブとして開けるようにした。
従来のダイアログ表示も残し、ダイアログの ⋯ →「タブに戻す」で移せる。

## 使い方

- タイル見出しの ＋▾ →「リモートデスクトップ ▸」→ デバイス、またはパレットの
  「リモートデスクトップをタブで開く」。
- タブは端末のタブと同じく、ドラッグで移動・「右に切り出す」で分割・仮想デスクトップ間で移動できる。
- 同じデバイスの画面タブは 1 枚に畳む（もう一度開くと既存のタブを前に出す）。
- 画面タブの見出しは 1 段。状態・見るだけバッジ・⌨（文字入力）・Esc は、`RemoteScreen` がタイル見出しの差し込み口
  （`TabStrip` の `.strip-screen`、`SplitView` が葉ごとに持ち、`TerminalTabs` 経由で前面の画面タブだけに渡す）へ
  `createPortal` で描く。全画面のときと差し込み口が無いときは、画面の上に同じ部品を出す。
  幅 290px 以下では Esc と状態の文字を省き、Esc は画面メニューに入る。
- 画面メニュー（`menus.ts` の `SCREEN_MENU`、`commands.ts` の screen スコープ）は、画面タブではタブメニューの先頭の段、
  ダイアログでは見出しの ⋯。「ダイアログで大きく表示」で従来のダイアログに移し、ダイアログの「タブに戻す」で戻せる。
  「別のデバイスに切り替え ▸」は、タブではそのタブのデバイスを差し替える（そのデバイスの画面タブが既にあればそちらを前に出す）。
- スマホの画面タブでは入力行が画面用のキー（Esc Tab ↑ ↓ ← → Enter Ctrl Alt）と［⌨ 文字入力］になる。
  Ctrl・Alt は次のキーと一緒に送ってすぐ離す（リモートに押したまま残さない）。
  見出し 1 行のスマホではタイル見出しが隠れるため、差し込み口は使わず、状態と見るだけバッジを画面の右上に重ねる
  （`SplitView` の `stripHidden` → `RemoteScreen` の `floatHead`）。文字入力は画面メニューからも開ける。
- 画面タブが前面のときも「新しい端末を右に並べる」「Claude / Codex を起動」は、そのデバイスの
  セッションで開く。

## 設計

- `web/src/layout.ts`: タブを `TerminalTab | ScreenTab`（`kind: 'screen'`, `deviceId`）の判別共用体にした。
  "desktop" は仮想デスクトップの意味で使っているので、種類名は `screen`。
  tmux との突き合わせ（`pruneStale` / `remapByName` / `stampNames`）は画面タブを素通しする。
  `migrate` は不正な `deviceId` や未知の `kind` のタブを落とす。
- サーバ（`server/src/workspace-sync.js`）は `kind: 'screen'` と `deviceId` の形式を検査し、未知の種類は拒否する。
- `web/src/components/RemoteScreen.tsx`: ダイアログとタブで共通の画面部品。`ScreenViewer` はその薄い包み。
- 接続の節約:
  - 隠れて 30 秒（`SCREEN_IDLE_MS`）経ったら切断し、表示したら繋ぎ直す。すぐ戻ったときは繋いだまま。
    ページ自体が裏に回ったときも同じ。
  - サーバは接続ごとに x11vnc を 1 つ起動するため、同じデバイスの画面はページ内で 1 か所だけ繋ぐ
    （`web/src/screen-lease.ts`）。後から表示したものが接続を取り、元の表示は「別の場所で表示中」になる。
    持ち主が手放すと、表示中で待っているものに自動で渡る（ダイアログを閉じるとタブが繋ぎ直す）。
- キー操作:
  - Alt+数字などアプリのショートカットはアプリ側で処理する（タブの中では Escape も小窓を閉じるだけ）。
    見出しへ差し込んだ部品のキー入力も React の木を通って画面の `onKeyDown` に届くので、Escape で文字入力を閉じ、
    フォーカスは ⌨ に戻る。ダイアログのフォーカスの閉じ込めと Escape（小窓・メニュー → ダイアログの順に閉じる）は変えていない。
  - 画面からフォーカスが外れたら、押したままのキーをリモートで離す（Alt+数字で移ったとき Alt が
    押されたまま残らない）。
  - Ctrl+ホイールは端末の文字サイズ変更ではなくリモートへ送り、ページの拡大は抑える。
- 全画面のままタブを切り替えたら全画面を終了する（隠れた要素が全画面に残るのを防ぐ）。
- 縮小表示の余白は端末と同じ黒。タイル内ではノッチ等の安全領域を足さない（全画面のときだけ足す）。

## 確認

```bash
cd web && npm test                 # 画面タブの単体テスト（test/screen-tabs.test.ts）を含む
cd server && npm test              # 同期で画面タブを受け付け、不正な形を拒否する
SCREEN_TAB_CHECK=1 SCREENS=terminal-target node web/test/visual-feedback.cjs after
```

`SCREEN_TAB_CHECK` はテスト用の最小 RFB サーバに実際に繋ぎ、1 段の見出し・Esc・画面メニュー・見るだけ・画質・
文字入力（Escape と ⌨ へのフォーカス戻し、キーとして送る）・お知らせの ×・スマホの画面用キー（Ctrl+Esc）・開く・重複しない・同期される・
Ctrl+ホイール・Alt の解放・30 秒の猶予と切断・ダイアログとの受け渡し・分割表示・スマホ幅を確かめる。
既存の画面別チェックは変更前後で結果が同じことを確認した。

## 既知の制限

- 画面タブを含む配置を古いバンドルのページが受け取ると、そのページは画面タブを落とし、
  配置を書き換えたときに同期先からも消える。PWA は新しいビルドに更新されるので一時的な問題として扱う。
- ショートカット用の Alt を単独で押して離すと、そのままリモートにも Alt が届く。
