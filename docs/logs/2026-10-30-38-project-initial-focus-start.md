## やろうとしたこと

プロジェクトダイアログを開いた直後と、新規作成・既存フォルダーを切り替えた直後に、キーボードだけで対象入力欄へ入力できることを確認する。

## 実際に起きたこと

コードでは React の autoFocus を使用している。共有 Modal は useEffect でネイティブ dialog を開くため、入力欄のフォーカス指定と開く処理の順序を合成データの Chromium・WebKit で調べる。まだ不具合と確定していない。

通知受信結果の読み取り時に、環境にない実行名を使用した。python3 に変更し、前工程の完了通知を確認できた。

```text
/bin/bash: line 1: python: command not found
```

## 原因

入力開始の挙動は未確認。診断コマンドの失敗は、この環境に python がなく python3 のみ存在するため。

## 試して却下した方法

挙動を確かめずに自動フォーカス処理を変更すること。

## 最終的な対応

一時的なブラウザー診断で、開いた直後の activeElement と、クリックせずにタイプした文字の入力先を確認する。

## 次にやる人が知っておくべきこと

実際のプロジェクト作成 API は呼ばず、既存の合成データ用ブラウザーフィクスチャーだけを使用する。診断の一時追記は確認後に削除する。
